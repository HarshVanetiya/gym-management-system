Next steps

Going live takes about a day

  1. 1Buy the domain (≈ ₹900/yr).
  2. 2Create the free Supabase project and load the database.
  3. 3Fill in the gym’s details, plans and photos.
  4. 4Add existing members, then share the login link with them.
Try it yourself

Live demo

Run npm install then npm run dev and open localhost:3000/login.

Use the one-click buttons: Trainer to manage the gym, Member · Neha to see the member app with a pending payment.

Demo data stays in your browser. “Reset demo data” at the top restores it.
