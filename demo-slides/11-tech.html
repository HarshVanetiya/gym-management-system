Under the hood

Built on dependable, low-cost tools

  • Next.js website and app: fast pages, readable by Google.
  • Supabase (Postgres database + logins), Mumbai region.
  • Database security rules: a member can only ever see their own data, and only the trainer can change payments.
  • Nightly backup to GitHub, free.
  • India network fix: Supabase was blocked on some ISPs in 2026, so the app can run through the gym’s own domain.
Member logins

Trainer saves the member’s email → member signs up with it → their plan appears automatically. Email confirmation proves it is really them.

Demo mode

Without a database the app runs on sample data in the browser, which is how this demo works offline.

Owned by the gym

All data can be exported any time. No lock-in to a gym-software vendor.
